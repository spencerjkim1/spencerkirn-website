How this demo works

Browser → POST /api/demo/process → Worker → JSON. The browser sends {"dataset":"large"}. The Worker generates 600 bundled synthetic orders, validates them, calls the displayed transform, and returns the results. The browser does not execute the transform.

This preview runs on your machine. Once deployed, requests run on Cloudflare and show the handling location when available. The endpoint currently shares the website’s Worker; it is not a separately deployed demo service.

The deploy command assumes Node.js, an authenticated Cloudflare account, and a configured Wrangler project with any required bindings. The displayed file is a processing module, not a complete standalone Worker. No deployment has been triggered by viewing this page.

Request size and frequency are limited. No database, object storage, external API, or deployment credentials are used by Run Worker. Round-trip time is measured in the browser—not CPU billing or a benchmark against AWS or GCP.
