2. Custom WAF rule

Deterministic live demo
2

Create a business-specific control

In Cloudflare, open Security → Security rules → Create rule → Custom rules.

  • Rule name: DEMO — block custom query
  • Action: Block (or Managed Challenge if you want to demonstrate user verification)
(http.host eq "spencerkirn.com" and starts_with(http.request.uri.path, "/appsec") and http.request.uri.query contains "cf-demo=custom-rule")

The hostname, path, and unique query parameter prevent this rule from affecting the rest of the site.

Open allowed control Trigger custom rule

Expected result

The control URL should load normally. The trigger URL should show Cloudflare's block or challenge response after the rule is deployed.

Prove it

Open Security → Analytics → Events. Filter to the host/path and service Custom rules. Expand the event and show its action, rule, source, path, and Ray ID.

3. Rate limiting

Low-volume owned test
3

Create the rate-limit rule

Open Security → Security rules → Create rule → Rate limiting rules.

  • Name: DEMO — appsec burst
  • Characteristic: IP
  • Example threshold: 5 requests in 10 seconds
  • Action: Block
  • Mitigation timeout: 10 seconds, if your plan exposes it
  • Cached assets: Include them; this page is a static asset
(http.host eq "spencerkirn.com" and starts_with(http.request.uri.path, "/appsec") and http.request.uri.query contains "rate-test=")

Run 12 requests

The test sends a small sequential burst to this owned page. Early requests should succeed; later requests should normally return 429 after the rule takes effect.

Not run

Distributed enforcement can lag slightly, so the exact transition request may vary.

Prove it

Open Security → Analytics → Events. Filter service to Rate limiting rules and path to /appsec. Show the action, threshold, source, path, and Ray ID. Disable the rule after the session.

5. Additional layers

Guided discussion

Bot controls

Under Security → Settings, filter by Bot traffic.

  • Free: Bot Fight Mode
  • Pro/Business/Enterprise: Super Bot Fight Mode
  • Enterprise add-on: Bot Management score and analytics

Do not promise a 1–99 bot score on every plan. Bot Fight Mode is coarse and cannot be skipped by a custom rule.

Turnstile

Use Turnstile for signup, login, and checkout abuse. A real implementation requires server-side Siteverify validation; a widget by itself does not secure a form.

Tokens expire after five minutes and are single-use.
